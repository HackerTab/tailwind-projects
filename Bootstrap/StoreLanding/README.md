# Store Landing — Responsive Design

Files included:
- `index.html` — landing page HTML (Bootstrap 5 CDN + custom styles)
- `styles.css` — custom CSS to complement Bootstrap

Design choices:
- Used **Bootstrap 5** for grid, responsive utilities and components (navbar, cards, buttons).
- Minimal custom CSS for hero look, product card hover, and responsive tweaks.
- Placeholder images use `picsum.photos` so layout and responsiveness can be verified without assets.
- Accessibility: images include `alt` text, focus styles on buttons, and nav links use smooth scrolling to anchors.

How to preview:
1. Open `index.html` in your browser (double-click or right-click → Open with Live Server extension in VS Code).
2. Resize the browser or use dev tools to test mobile breakpoints.
